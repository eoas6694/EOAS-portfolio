# AIPPLY

High Volume job assistant

## Description

A localized job application utility designed to assist job seekers aggregate job listings, streamline applications, and track progress. 

## Getting Started

This program is entirely local so simple copy it into your desired directory and double click to launch.
For best results: link an ai model

### Executing program

1. Double click AIPPLY.html from file explorer to launch into your default browser.
2 Select Profile in the the left pane and input your account information
3. Select settings in the left pane and click the job boards you would like to search in the "Suggested Sources" field.
4. select Job Queue in the left pane and search for target roles. 
5. select a job positing from queue and approve and skip at the bottom to  apply. Repeat steps 2-5 per role
6. Track your applications as until a job has been secured
